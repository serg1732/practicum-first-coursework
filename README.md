# Gophermart

Накопительная система лояльности для интернет-магазина.

Сервис позволяет пользователям накапливать бонусные баллы за покупки и использовать их для оплаты новых заказов.

---

## Возможности

- Регистрация и аутентификация пользователей
- Загрузка номеров заказов
- Получение информации о начислениях из внешней системы
- Учёт и хранение бонусного баланса
- Списание баллов в счёт оплаты заказов
- Просмотр истории списаний

---

## Бизнес-логика

1. Пользователь регистрируется в системе
2. Загружает номер заказа
3. Сервис отправляет номер заказа в систему начислений
4. После обработки заказа пользователю начисляются баллы
5. Баллы можно использовать для оплаты новых заказов

---

## HTTP API

### Аутентификация

- `POST /api/user/register` — регистрация пользователя
- `POST /api/user/login` — аутентификация пользователя

### Заказы

- `POST /api/user/orders` — загрузка номера заказа
- `GET /api/user/orders` — список заказов пользователя

### Баланс

- `GET /api/user/balance` — текущий баланс
- `POST /api/user/balance/withdraw` — списание баллов

### Списания

- `GET /api/user/withdrawals` — история списаний

---

## Конфигурация

Сервис поддерживает настройку через переменные окружения или флаги:

| Переменная              | Флаг | Описание                              |
|-------------------------|------|----------------------------------------|
| RUN_ADDRESS             | -a   | адрес HTTP-сервера                    |
| DATABASE_URI            | -d   | строка подключения к PostgreSQL       |
| ACCRUAL_SYSTEM_ADDRESS  | -r   | адрес системы начислений              |
